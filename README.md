# Локальные агенты

Локальное управление агентами, разговорами и подключениями Яндекс AI Studio с текстовыми ответами выбранной модели. Python 3.10+, FastAPI, SQLite, обычные HTML/CSS/JavaScript без сборщика. Интерфейс на русском.

## Установка в Windows

Откройте папку `hacking` в VS Code и терминал PowerShell. Нужен установленный Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `py` отсутствует или не находит установленный Python, используйте `python -m venv .venv` либо полный путь к интерпретатору. Активировать окружение не требуется.

## Запуск

Дважды щёлкните `Запустить.bat` или выполните:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000 . Для остановки сервера нажмите Ctrl+C в его терминале. При занятом порте остановите предыдущий экземпляр или задайте другой `--port`.

## Возможности

- Удаление отдельного чата кнопкой «Удалить» рядом с его названием, с подтверждением. Удаляются сообщения и история запросов этого чата. Во время генерации сначала нажмите «Остановить».
- Создание, редактирование и удаление агентов с подтверждением. Обязательное имя, описание и инструкция.
- Вкладки «Чат» и «Настройки», отдельные разговоры, история сообщений. Название разговора берётся из первого сообщения.
- Сообщения пользователя и реальные текстовые ответы модели сохраняются в SQLite. Ошибки и уведомления интерфейса не записываются как ответы агента.
- Выбор подключения и модели в форме «Новый агент» и в настройках. Можно создать агента без модели и назначить её позже. При смене подключения выбор модели очищается.
- Если модель выбрана, отправка сообщения запускает запрос к Яндекс AI Studio с инструкцией агента и историей текущего разговора. «Остановить» прерывает ожидание ответа, «Получить ответ» позволяет повторить запрос на последнее сохранённое сообщение. Веб-поиск и интерпретатор кода включаются чекбоксами. Авторизация пользователей и взаимодействие агентов не реализованы.
- Ошибки отображаются в интерфейсе; неудачная отправка или сохранение не очищает поля. Черновики сообщений сохраняются в памяти вкладки при переключении разговоров; после перезагрузки страницы остаются только отправленные сообщения.

## Подключение Яндекс AI Studio

1. Перезапустите сервер после обновления и откройте раздел «Подключения».
2. Нажмите «Добавить подключение», введите название, API-ключ и ID каталога (Folder ID).
3. Нажмите «Получить модели». Это работает до сохранения: отображаются полный список, количество и время успешного получения. Поиск выполняется по точному ID, рядом показан производитель.
4. Нажмите «Сохранить». Полученный список сохраняется вместе с подключением, без повторного запроса. Предварительный результат хранится в памяти сервера до 30 минут; если сервер перезапущен или срок истёк, получите список заново. Поля ключа и каталога должны соответствовать полученному списку.
5. Для сохранённого подключения используйте «Обновить список моделей». При изменённых полях сначала сохраните форму или используйте «Получить модели» для проверки введённых данных.
6. Создайте агента или откройте его «Настройки». Под инструкцией выберите «Источник / подключение», затем модель и сохраните.

Используется [официальный Models API](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/models/get): `GET https://ai.api.cloud.yandex.net/v1/models`, заголовки `Authorization: Api-Key <ключ>` и `x-project: <Folder ID>`. По инструкции нужны роль сервисного аккаунта **`ai.languageModels.user`** и область действия API-ключа **`yc.ai.models.viewer`**.

Запрос выполняет сервер только по нажатию кнопки получения/обновления. Сетевой тайм-аут — 20 секунд. Ошибки доступа, сети и некорректного ответа показываются в интерфейсе; прежний успешный список и его дата сохраняются. Смена Folder ID оставляет прежний список с предупреждением до обновления.

Все записи `data[]` сохраняются с исходными `id`, `owned_by`, `object`, `created`, без фильтра по производителю. Список может включать эмбеддинги и модели других производителей. Наличие модели в списке не означает поддержку чата или инструментов. Генерация при получении списка не запускается; подготовленных списков для замены API нет.

Если выбранная модель исчезнет из списка, её ID останется у агента с предупреждением. Автоматической замены нет. Удалить назначенное агентам подключение нельзя: ошибка перечислит агентов, у которых нужно изменить подключение.

## Чат с моделью

Чекбоксы управляют группами `web_search` и `code_interpreter`. В публичном API нет отдельных переключателей `web_search_with_grep`, `web_search_read`, `list_files` и `execute_python_code`; эти названия в ответе модели сами по себе не подтверждают реальные вызовы. При обоих выключенных чекбоксах инструменты не передаются, а `tool_choice` задаётся как `none`. Python имеет доступ к файлам контейнера Яндекса, а не к рабочей папке этого приложения.

В форме создания и настройках агента доступны чекбоксы **«Веб-поиск»** и **«Интерпретатор кода (Python)»**. Они сохраняются отдельно для каждого агента и по умолчанию выключены. После изменения нажмите «Сохранить изменения».

Если включён хотя бы один инструмент, запрос идёт через `POST https://ai.api.cloud.yandex.net/v1/responses`: `web_search` разрешает модели искать в интернете, `code_interpreter` с `container: {"type": "auto"}` разрешает выполнять Python в контейнере Яндекса. Модель сама решает, нужен ли инструмент. При выключенных чекбоксах используется Chat Completions. Поддержка зависит от выбранной модели и прав аккаунта; автоматической подмены модели нет. Для Responses и интерпретатора проверьте роли `ai.assistants.editor`, `ai.languageModels.user` и область ключа `yc.ai.foundationModels.execute`. Использование инструментов оплачивается по тарифам Яндекса; поиск расходует квоты Yandex Search API.

Источники из аннотаций веб-поиска сохраняются в конце ответа. Интерпретатор поддерживает вычисления с текстовым результатом; загрузка входных файлов и скачивание созданных файлов в приложении пока не реализованы. Контейнер создаётся автоматически для запроса, состояние Python между сообщениями не сохраняется. Тайм-аут остаётся 120 секунд, поэтому длительная задача может потребовать повторной попытки.

Документация: [веб-поиск](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/agents/tools/websearch), [интерпретатор кода](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/agents/use-code-interpreter).

После обновления установите зависимости командой `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`, перезапустите сервер и обновите страницу через Ctrl+F5.

Откройте карточку агента → «Чат» → «＋ Новый», введите текст и нажмите «Отправить». На уже сохранённое последнее сообщение можно запросить ответ кнопкой «Получить ответ», без повторного ввода. Для агента без модели отправка по-прежнему только сохраняет сообщение.

Используется [официальный Chat Completions API](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-basic): `POST https://ai.api.cloud.yandex.net/v1/chat/completions`, `Authorization: Api-Key <ключ>` и `OpenAI-Project: <Folder ID>`. Для генерации нужны роль **`ai.languageModels.user`** и область действия ключа **`yc.ai.foundationModels.execute`**. Область `yc.ai.models.viewer` даёт только просмотр списка. При ошибке доступа измените права или замените ключ через «Подключения».

В запрос передаются точный выбранный ID модели, инструкция агента как `system` и только история этого разговора. Текст отправляется провайдеру после «Отправить» или «Получить ответ». Чекбоксы разрешают встроенные инструменты Яндекса; описание роли агента само по себе таких возможностей не добавляет.

Ответ появляется целиком, без потокового вывода, и сохраняется с ролью `assistant`. Общий тайм-аут запроса — 120 секунд; лимит ответа — 4096 токенов. Если модель исчерпает лимит, появится уведомление. История не обрезается автоматически: при превышении контекста начните новый разговор. Эмбеддинги и другие модели без Chat Completions могут вернуть ошибку; приложение не заменяет выбранную модель.

В одном разговоре выполняется один запрос. Повторное обращение к выполняющемуся/завершённому запросу не создаёт второй ответ. После ошибки или остановки повтор запускается только вручную. Кнопка «Остановить» отменяет HTTP-запрос на нашем сервере и не сохраняет поздний ответ; она не гарантирует отмену обработки или начислений на стороне Яндекса. При потере связи обновите страницу: статус и готовый ответ читаются из базы. При перезапуске сервера незавершённый запрос получает ошибку и может быть повторён вручную.

Запускайте один процесс сервера (без `--workers`): задачи генерации выполняются в памяти одного процесса, их результаты и статусы хранятся в SQLite.

## Данные, ключи и структура

База автоматически создаётся в `data/agents.sqlite3`, путь не зависит от текущего каталога запуска. Миграция добавляет поддержку роли `assistant` и таблицу состояний запросов `generations`, сохраняя ID, текст и даты прежних сообщений. Существующие агенты, разговоры, подключения и выбор моделей сохраняются. Удаление агента также удаляет его разговоры и сообщения.

API-ключи находятся только в отдельных серверных файлах `secrets/*.key`, **без шифрования**. Ключей нет в SQLite, ответах API, HTML и журналах приложения; интерфейс получает только признак «Ключ сохранён». Пустое поле при редактировании сохраняет прежний ключ. Введённый ключ очищается из формы после успешного сохранения. Папка `secrets/` не раздаётся HTTP-сервером и исключена из Git. Для резервной копии остановите сервер и скопируйте `data/` и `secrets/` в защищённое место.

- `app/main.py` — HTTP API, валидация и запуск приложения.
- `app/db.py` — подключение, транзакции и схема SQLite.
- `app/connections.py` — управление подключениями, кэшем и проверка выбора модели.
- `app/chat.py` — запуск, отмена и сохранение результатов запросов модели.
- `app/providers/yandex_chat.py` — асинхронный адаптер Chat Completions без инструментов.
- `app/secret_store.py` — серверное файловое хранилище ключей.
- `app/providers/yandex.py` — отдельный адаптер Models API; реестр адаптеров в `app/providers/__init__.py` позволяет позже добавить другие источники. LM Studio, OpenAI и Gemini сейчас не реализованы.
- `app/static/` — интерфейс без внешних библиотек и CDN.
- `tests/test_app.py` — интеграционные проверки реального HTTP-сервера на временной БД, включая перезапуск процесса.
- `tests/test_connections.py`, `tests/support.py` — подставные HTTP-ответы провайдера, подключения, секреты, выбор модели и миграция старой схемы.
- `tests/test_chat.py` — запросы и ошибки Chat Completions, контекст разговора, отмена, повтор, защита от дублирования и восстановление после перезапуска.

Пользовательский текст вставляется через `textContent`, SQL использует параметры. `data/`, `.venv/`, `.env*`, `secrets/` и ключи исключены из Git. Приложение предназначено для локального доступа на `127.0.0.1`: авторизации нет, данные в SQLite не зашифрованы.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты не затрагивают рабочую базу и не обращаются к Яндексу. Проверяются CRUD агентов, изоляция разговоров, сохранность сообщений и выбора модели после перезапуска, полный список и точные ID моделей, ошибки авторизации/сети/тайм-аута/повреждённого ответа, сохранение кэша при ошибках, отсутствие ключей в API, запрет удаления используемого подключения и сохранность данных при повторной миграции старой схемы.

Реальное подключение без ключа, введённого пользователем через интерфейс, не проверено. Подставные ответы подтверждают поведение приложения, но не доступ конкретного аккаунта к Яндекс AI Studio.
